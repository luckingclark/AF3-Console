# Related tools: capabilities and focus

[中文](comparison.zh-CN.md) · [Back to README](../README.md)

Reviewed **2026-09-13** against the official READMEs linked in each row. This is a documentation-based comparison of capabilities and workflows; the tools were not installed for comparative testing. Speed, resource use, and prediction quality are outside its scope. Omitted features are unverified here, not necessarily unsupported.

| Project | Capabilities and interface | Focus and relationship to AF3 Console |
|---|---|---|
| [AF3 Console](../README.md) | Bilingual Qt desktop and CLI; Slurm submission, monitoring, continuation and retry; two-group screens, fixed-window / PAE-guided scans, MSA reuse and result inspection. | Combines everyday AF3 cluster operations in one workbench. Targets Linux + Slurm + Singularity + X11; see [validation](validation.md) for real-cluster testing status. |
| [AlphaPulldown](https://github.com/KosinskiLab/AlphaPulldown#readme) | AlphaFold 2, AlphaFold 3 and AlphaLink backends; combination screens, region/copy expressions, precomputed features / MSA reuse; companion AlphaJudge and APLit tools for analysis and inspection. | A complex-modelling toolchain spanning several prediction backends. Screening, fragment input and MSA reuse overlap with Console, which concentrates on AF3 desktop and CLI operation. |
| [AlphaPulldownSnakemake](https://github.com/KosinskiLab/AlphaPulldownSnakemake#readme) | Sample tables and configuration define AlphaPulldown tasks; Snakemake manages local or Slurm execution, retries, feature reuse and result aggregation. | Workflow-engine management of batch computations overlaps with Console's Slurm task management. This is a related AlphaPulldown workflow wrapper, currently recommended upstream for running it. |
| [AFusion](https://github.com/Hanziwww/AlphaFold3-GUI#readme) | Streamlit browser UI; AF3 JSON for proteins, RNA, DNA and ligands; MSA/template/modification/bond configuration, Docker execution with output display, Python batch API, structure/PAE visualization. | Browser-based AF3 input, execution and inspection overlap with Console's graphical operations. Its documented execution uses Docker; Console targets Qt desktop operation with Slurm/Singularity. |
| [af3_pulldown](https://github.com/luisherfurth/af3_pulldown#readme) | Staged scripts and Slurm arrays for one bait against multiple candidates as two-chain AF3 jobs; bait MSA reuse, external AFM-LIS scoring and summary heatmaps. | Focuses on single-bait screening and LIS/iLIS analysis. Console provides two-group protein or complex combinations, fragment scans and a shared task interface; consult each project's documentation for its scoring features. |
| [AFragmenter](https://github.com/sverwimp/AFragmenter#readme) | PAE domain segmentation using Leiden clustering with adjustable resolution and filters; Notebook/Python/CLI use, PAE/structure visualization, CSV and domain FASTA export. | Focuses on exploring and exporting domain segmentations. Console connects segmentation to fragment-window generation and subsequent AF3 jobs; the segmentation implementations differ. |
| [pae_to_domains](https://github.com/tristanic/pae_to_domains#readme) | Embeddable Python code and CLI; PAE-to-residue-cluster conversion and CSV export, NetworkX or igraph backends, adjustable thresholds and resolution. | Focuses on a reusable segmentation component. Console supplies scanning, scheduling and a UI around related methods; [algorithm provenance](algorithm-provenance.md) identifies its actual source adaptations. |

Choose according to the workflow you need: a workflow engine, several prediction backends, browser operation, a dedicated screen, or standalone domain analysis. Console's focus is integrated bilingual desktop and CLI operation; the capabilities listed here are not claimed to be exclusive.

AFusion's public input demo only generates JSON; execution above refers to its locally installed toolkit. AlphaJudge/APLit are companion projects. This comparison does not imply that Console integrates all listed tools; see [third-party notices](../THIRD_PARTY_NOTICES.md) for code and assets actually reused.
